A simple Windows desktop app to help you organize your daily routines, build good habits, and stay on top of your schedule.

---

## Features

- **Daily Task Tracking**: Add your tasks, set their times, and check them off as you go.
- **Routines & Pages**: Organize tasks into different lists—like Morning Routine, Work, Gym, or Study.
- **Sidebar Notes**: Add quick notes and checklists directly in your sidebar with customizable emoji badges.
- **Reminders & Alerts**: Helpful sound alerts and notifications when it's time to begin a task.
- **Prayer Times**: Shows your daily prayer schedule automatically throughout the day.
- **Share Routines**: Export your routine and notes to share with others or import someone else's setup in seconds.
- **14 Signature Themes**: Choose between 8 dark and 6 light themes with accurate dual-tone color previews.
- **1,200+ Emojis**: Personalize tasks and notes with full emoji categories and smart search.

## Running from Source

### Quick Start (PowerShell - One Line)
Paste this single command into PowerShell to download, install dependencies, and launch automatically:
```powershell
cd $HOME; git clone https://github.com/Moham-OverKill/Daily-Tasks.git; cd Daily-Tasks; .\run.bat
```

### Step-by-Step
```powershell
# 1. Navigate to your user directory (avoids permission errors if terminal started in System32)
cd $HOME

# 2. Clone and enter the repository
git clone https://github.com/Moham-OverKill/Daily-Tasks.git
cd Daily-Tasks

# 3. Run the automated setup launcher
.\run.bat
```

## Privacy Policy

Daily Tasks is an offline-first desktop application. All data, tasks, notes, and user settings are stored locally on your device in `%APPDATA%\DailyTasks`. No personal data, tracking identifiers, or telemetry are collected, transmitted, or shared.
